      AI Code Session Widget

      Shows your running Claude Code and Codex sessions and what each one is doing. It only reads the session files the agents write; no network, no API keys.

      • Click a session to bring its window forward.
      • Filter chips hide statuses, the buttons beside them sort.
      • Tray icon: click brings the widget to the front (pinned to the desktop: for 5 s), right-click for the menu with Hide widget.
      • Right-click for window, view and click settings. Pin to desktop keeps the widget on the desktop like a gadget: below all windows, no taskbar button, still there after Win+D. Show in taskbar hides the button in the other modes; the tray icon stays.
